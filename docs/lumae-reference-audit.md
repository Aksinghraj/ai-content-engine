# Reference-Site Design Audit: FUERA

**Source reviewed:** `https://www.fuera.in.net/` on 23 August 2026.

## Observable interaction and structure patterns

The reference presents a high-density marketing-site flow built around a broad, multi-level navigation system, prominent inquiry calls to action, interactive service discovery, rotating or stepped content controls, expandable FAQ items, case-study content, testimonial navigation, and a long-form contact capture section. The visible interactive inventory includes theme control, navigation groups, multiple “Explore More” and “Get Started” calls to action, carousel-like slide controls, package actions, testimonial controls, and a detailed inquiry form.

## Originalizable principles for Lumae

Lumae can adopt the **behavioral principles** without copying content, identity, layouts, assets, or text: a more editorial public narrative; active but restrained section transitions; clear service/product discovery; a stronger progression from product value to proof to conversion; responsive feedback on interactive controls; and a clear end-of-page conversion path.

## Lumae-specific boundary

The redesign must retain Lumae’s existing routes, security, privacy, account, dashboard, and accessibility systems. The result will use Lumae’s own visual vocabulary and content rather than FUERA’s agency-oriented service catalog, pricing structure, contact copy, or branding.

## Design direction to test

Use a distinct Lumae **midnight obsidian + mineral teal + warm coral** palette, an editorial display type scale, subtle spatial depth, a 3D-free luminous grid treatment, 150–220ms interaction feedback, and reduced-motion fallbacks. Public pages may use richer scroll-driven pacing; authenticated product pages should keep only purposeful state transitions and maintain fast scanability.
