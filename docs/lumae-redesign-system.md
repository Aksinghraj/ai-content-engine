# Lumae Experience Redesign System

## Intent

Create a richer, more deliberate Lumae experience across marketing, authentication, and product surfaces. The redesign borrows only general interaction principles from the reviewed reference—editorial pacing, layered discovery, visible progression, and responsive feedback—while preserving Lumae’s independent identity, content, routes, and functionality.

## Visual language: "Signalfield"

Lumae becomes a calm signal workspace: deep obsidian surfaces, mineral teal fields, warm coral decision points, and a cool ivory reading layer. The earlier purple/cyan style is replaced by an original palette that has higher contrast and clearer hierarchy.

| Token | Value | Purpose |
|---|---:|---|
| Obsidian | `#0A1116` | Primary dark canvas and app chrome |
| Ink | `#111C22` | Elevated surfaces and dashboard panels |
| Slate mist | `#63747C` | Secondary text and supporting metadata |
| Cloud | `#F5F7F6` | Light theme/background and primary light text |
| Mineral teal | `#2DD4BF` | Primary action, active states, and AI signal |
| Sea glass | `#78E2D0` | Gradient extension and selected highlights |
| Warm coral | `#FF6B5F` | Conversion focus, alerts, route markers, and key moments |
| Positive | `#38C892` | Success states; warning/error stay semantically distinct |

## Type and layout

Public pages use a more editorial hierarchy: wide, compact display headings with tight tracking, calm body copy, and deliberate asymmetry. Product surfaces use denser but still breathable data layouts. Navigation and cards have sharper radii, fewer floating borders, and more continuous panels.

## Motion and interaction

Public routes may use slow signal-field shifts, scroll section reveals, staggered proof rails, and 150–220ms hover feedback. Authenticated routes remain scan-first: only navigation selection, buttons, menus, loading, and real AI activity animate. The existing Lumae Light Pulse remains the only AI-working indicator and is never replaced with generic decorative loaders. All new motion has a reduced-motion static fallback.

## Scope

1. **Public:** Transform the landing page into a staged product story: signal hero, workflow proof, platform rail, security proof, and strong conversion close.
2. **Authentication:** Replace the dark orb aesthetic with a structured Signalfield backdrop, clear progressive sign-in panels, and an account-security reassurance panel.
3. **Product:** Restyle the sidebar, compact navigation, grouped tabs, and dashboard foundation so the app feels like an operating environment rather than a generic card dashboard.
4. **Non-negotiables:** Preserve routes, security behavior, responsive layout, high contrast mode, reduced-motion behavior, payment flows, OAuth, and all current product content.
